# Foundation Only Features

The following capabilities are built architecturally but require actual external vendor integration (API Keys/Contracts) to exit "Foundation" mode:

- **L3 Billing**: ZATCA E-Invoice physical XML submission (Mock/Manual verification only currently).
- **L4 Contracts**: E-Signature physical payload dispatch (Provider adapter requires implementation).
- **L7 Compliance**: Nafath Identity Verification & Sanctions Screening (Dow Jones/Refinitiv). The system securely records manual reviews but cannot ping real government lists without keys.
